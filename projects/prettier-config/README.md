# @dyrkow/prettier-config

## Setup

```
yarn add prettier @dyrkow/prettier-config -D
```

## Usage

Connect the config in your project in one of the following ways:

- **Option A:** Create a `.prettierrc` file in the project root with a single line: `"@dyrkow/prettier-config"`.
- **Option B:** Add to your project's `package.json`: `"prettier": "@dyrkow/prettier-config"`.
